# 運用と制限

## 状態

単一プロセス、単一の許可ユーザー、単一SuperSyncアカウント向けです。
同じdata/を共有する複数レプリカはサポートしません。
鍵の異なる別アカウントへ切り替えるときは、既存data/を再利用しないでください。

data/operations.sqlite:
- operations: 暗号化されたサーバー操作ログ
- metadata: ダウンロード位置、同期クロック、clientId、counter
- outbox: 暗号化送信本文、要求ID、引数のHMAC、タスクID、処理結果

読取りは15秒キャッシュし、書込み前に強制同期します。
欠落時は全量取得候補の復号・再生が成功した場合だけ読取りキャッシュを交換します。
clientIdとoutboxは保持します。送信結果が不明なpending要求は同じ要求で再試行します。

## バックアップ

SuperSync DBとMCPのdata/・secrets/を別々に扱います。
バックアップには資格情報が含まれるため、暗号化・アクセス制限を行ってください。
SQLiteはbackup API、またはMCP停止後のコピーを使用し、稼働中のDB本体だけをコピーしないでください。
バックアップの世代管理と復元試験は運用側で設定します。

MCP更新を戻すときは対応するsrc/・dist/・依存バージョンの組を戻し、data/・secrets/を保持します。
通常のMCPロールバックでSuperSync DB全体を古いバックアップへ戻さないでください。
他端末による新しい変更まで巻き戻す可能性があります。

## 制限

- upstream.jsonの固定リビジョンとschema 4を基準とした実験的アダプター。
- 不明な操作、未対応schema、復号不良、解消できない欠落はエラーを返す。
- 同一エンティティ競合はSuperSync側の拒否に従う。自動上書きはしない。
- 因果関係が確定できないREPAIRは停止する。
- 公式GUIの全Effectsは再現しない。外部Issue更新・通知は実行しない。
- 全量再生・ダウンロードに上限がある。大規模データや長期運用は個別に検証が必要。
- MCPサービスが侵害されると、復号可能な同期データにアクセスされる。信頼できるホストで動かす。

## 停止・資格情報

docker compose stop mcpでサービスを停止できます。
Keycloakのwriteロール削除は、既発行アクセストークンの失効までは即時反映されない場合があります。
即時遮断にはMCP停止またはプロキシ遮断を使用します。

SuperSyncのreplace-tokenは他の端末のトークンも失効させるため、この実装では呼びません。
期限切れなどで資格情報を更新する場合は、SuperSync本体の手順に従ってください。

## 実データ試験

src/smoke-read.tsは読取り確認です。
src/smoke-write.tsは専用テストアカウントへの実書込み試験であり、通常テストには含めません。
確認タスクは完了状態で残り、IDはdata/last-smoke-task.jsonへ記録します。
本番アカウントで無断の自動実行はしないでください。
